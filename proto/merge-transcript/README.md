# merge-transcript — 2トラックを時刻で統合する

`dual-capture` が録った2本の WAV の文字起こしを、**実時刻で突き合わせて**
`自分:` / `相手:` のラベル付きトランスクリプト1本にする。

**このツールは WSL で動く。**音声デバイスに触らないので、Windows 側である必要がない
（`dual-capture` とはそこが違う）。

---

## なぜ単純に並べられないか

**WAV の中の時刻は実時刻ではない。**

WASAPI ループバックは再生中のアプリが無いとパケットを返さないことがあり、
相手が黙っていた分だけ WAV の時間軸が詰まる（ADR-004）。
マイク側も起動遅延と underrun のぶんだけ詰まる（ADR-006）。
whisper が返すのは **WAV 内の時刻**なので、そのまま並べると2トラックがずれる。

実測では、相手トラックの WAV 0.7秒 が実時刻 10.5秒 に対応していた。
**約10秒ずれる。**会話の順序が入れ替わるので、誰が何に答えたのか判らなくなる。

## どう直すか

`dual-capture` が `*-meta.json` に残した `drops_sec_len`（実時刻, 空いた秒数）から、
WAV 内時刻 → 実時刻 の変換を復元する。

```
累積ラグ   L_i = Σ len         i 番目までの空白の合計
段差の位置 W_i = at_i − L_i    その空白が WAV 上のどこで立つか
実時刻     t_real = t_wav + L(t_wav)   L(t) は W_i ≤ t を満たす最後の L_i
```

**先頭の空白も `drops_sec_len` に入っている**ので、この配列だけで復元できる。
`first_data_sec` は参考値で、統合には使わない（2つの原点を混ぜない）。

## 使い方

```
# 1. 2本の WAV を文字起こしする（JSON で出す）
whisper-cli -m ggml-large-v3-turbo.bin -l ja -oj -f dual-<epoch>-self.wav
whisper-cli -m ggml-large-v3-turbo.bin -l ja -oj -f dual-<epoch>-other.wav

# 2. 統合する
cargo run --release -- dual-<epoch>
cargo run --release -- dual-<epoch> --debug    # WAV 内時刻と補正量も出す
```

`<stem>-self-meta.json` / `<stem>-self.wav.json` / `<stem>-other-*` の4ファイルを読み、
`<stem>-transcript.txt` を書く。片方が無ければ、あるほうだけで続ける。

## 出力

```
会議トランスクリプト
録音: dual-1788502024
自分: Logi USB Headset H340 / 48000 Hz / 時刻補正 +0.25秒（空白 1 箇所）
相手: Logi USB Headset H340 / 44100 Hz / 時刻補正 +9.80秒（空白 2 箇所）
時刻は録音開始からの実時刻。WAV 内の時刻ではない（ADR-004）。

[00:00.2] 自分: おはようございます 今日はよろしくお願いします
[00:10.5] 相手: おはようございます。では始めましょう
[00:12.2] 自分: はい、そうですね
[00:17.8] 相手: 来週までに見積もりを出します
```

ヘッダに**補正量と空白の数を出している**のは、統合が効いたかを一目で確かめるため。
相手側の補正が 0 に近いのに会話が噛み合っていないなら、`drops_sec_len` を疑う。

同じ話者が **2秒以内**で続く発話は1行にまとめる。whisper は文単位で切るので、
そのまま出すと短い行の壁になり、読みにくいうえ要約にも効かない。

## テスト

```
cargo test
```

時刻変換の回帰テストが4件。うち1件は
**「境界ちょうどのセグメントが段差を飛ばして9.6秒ずれる」**バグを押さえたもの。
段差の位置は `at − 累積ラグ` という引き算で出すため丸め誤差が乗り、
`10.500 − 9.800` は `0.7000000000000002` になる。whisper の刻みは 10ms なので
セグメントは境界にちょうど乗りやすく、**素の `<=` だと静かに壊れる**。

## まだ無いもの

- **VAD（無音カット）** — 文字起こしの前段。時間を半減でき、無音区間での幻聴も減る
- **whisper の幻聴の除去** — 無音区間で定型句が出ることがある。ここでは何も捨てていない
  （黙って中身を落とすほうが危険なため）
- **相手が複数人いる場合の話者分離** — v1 の対象外。相手はまとめて `相手:`
